# Chaos Ball

## 项目简介
本项目是《虚拟现实开发引擎》的实践产物：**Chaos Ball**。这是一款快节奏的街机风格弹球游戏，结合了 Pinball 和 Breakout 的部分玩法。玩家在一个封闭的舞台中，需要利用自己的“减震器”将四种不同颜色的彩球（红、蓝、橙、绿）分别撞入对应颜色的角落球门中。同时，舞台中还有许多快速移动的黄色“混乱球（Chaos Ball）”对玩家进行干扰。

## 游戏规则
- **目标**：将所有 4 只彩色球分别推入对应颜色的角落球门。当 4 只球都进入正确的球门时，玩家获胜。
- **干扰**：舞台上的黄色“混乱球”会快速移动并干扰玩家和彩球。
- **特性**：
  - 玩家和球都不能离开舞台。
  - 所有对象均具有“超级弹性”，碰撞不会损失动量（通过自定义的物理材质实现）。
  - 彩球和混乱球的初始速度和方向是随机的。
  - 游戏不存在失败条件，只有完成时间的挑战。

## 开发技术点
- **场景构建**：使用地形(Terrain)和基本几何体(Cube)搭建游戏舞台，并进行纹理贴图。
- **物理系统**：运用刚体(Rigidbody)、碰撞器(Collider)和触发器(Trigger)。自定义 `Physic Material` 实现无动能损耗的完美反弹。
- **角色控制**：利用 Unity Standard Assets 中的 First Person Controller 进行改造，增加用于击球的“减震器(Bumper)”。
- **脚本编程**：使用 C# 编写游戏逻辑，包括随机速度生成、触发器检测、游戏状态管理和简单的 UI 界面显示。

## 运行方法
双击re2.exe以运行游戏。
